# 日常使用

不需要记住 Tempo 的全部功能。先用主面板找到事情，再记住自己最常用的一两个快捷键。

## 用主面板找到功能

按 `Alt + Space`（macOS 为 `Option + Space`）打开主面板，然后直接输入：

| 想做什么 | 可以输入 |
| --- | --- |
| 打开本机应用 | 应用名称 |
| 打开 Tempo 功能 | “剪贴板”“待办”“设置”等 |
| 使用插件 | 插件名称或关键词 |
| 新建待办 | 输入内容后选择“创建待办” |

Tempo 会把常用和最近打开的结果排在前面。你不需要先进入某个分类。

## 找回复制过的内容

按 `Ctrl + Shift + V` 打开剪贴板选择器，或在主面板搜索“剪贴板”。

- 选择一项即可按当前设置复制或粘贴。
- 固定重要内容后，清理历史时不会删除它。
- 可以在 **设置 → 插件管理 → 剪贴板** 中暂停记录或修改选择行为。

::: warning 敏感内容
剪贴板历史保存在本机，但仍可能包含验证码、密码或私密文字。不需要记录时，可以在剪贴板设置中关闭它。
:::

## 重复输入常用文字

“快捷短语”适合保存地址、回复模板、命令或其它经常重复输入的内容。

1. 在主面板搜索“快捷短语”。
2. 新建短语并填写标题与正文。
3. 按 `Ctrl + Shift + S` 随时打开短语选择器。

短语可以分组、固定和搜索。标题只负责帮你识别，真正复制的是正文。

## 记录待办

在主面板搜索“待办”，可以创建任务、设置截止时间、重复规则、子任务和备注。

更快的做法是先在主面板输入任务内容，再选择“创建待办”。例如输入“周五前提交周报”，无需先打开待办页面。

## 查看屏幕使用时间

搜索“屏幕使用时间”可以查看应用使用统计。统计来自本机前台窗口，不会上传到云端。

部分全屏、受保护窗口或系统限制下的应用可能无法被完整统计。如果数据一直为空，先查看 [遇到问题](/guide/troubleshooting#屏幕使用时间没有数据)。

## 修改快捷键与外观

在主面板搜索“设置”：

- **通用设置**：切换浅色、深色或跟随系统。
- **快捷键**：修改主面板、剪贴板和快捷短语的全局快捷键。
- **插件管理**：启用、停用或配置内置功能与第三方插件。
- **存储管理**：查看或修改本地数据位置。
