# 快速开始

这篇只讲第一次使用。完成下面三个步骤后，你就可以关掉文档。

## 安装 Tempo

从 [GitHub Releases](https://github.com/joooooooojo/tempo/releases) 下载最新版：

| 系统 | 下载文件 |
| --- | --- |
| Windows | `.msi` 安装包 |
| macOS | `.dmg` 或 `.app` 压缩包 |

安装完成后打开 Tempo。它会驻留在系统托盘或菜单栏，不需要一直显示一个窗口。

## 打开主面板

按下系统对应的默认快捷键：

| Windows | macOS |
| --- | --- |
| `Alt` + `Space` | `Option` + `Space` |

看到搜索框后，输入一个应用名，例如“设置”或“待办”。

1. 用 `↑` `↓` 选择结果。
2. 按 `Enter` 打开。
3. 按 `Esc` 返回或关闭面板。

::: tip 快捷键冲突
如果系统或其它应用占用了快捷键，先从托盘打开 Tempo，再进入 **设置 → 快捷键** 修改。
:::

## 完成第一次搜索

试着在主面板中搜索下面任意一项：

- `剪贴板`：查看最近复制过的文字和图片。
- `快捷短语`：保存并重复使用常用文字。
- `待办`：记录任务和提醒。
- `屏幕使用时间`：查看应用使用情况。

Tempo 也会搜索本机应用。直接输入应用名称，按 `Enter` 即可打开。
