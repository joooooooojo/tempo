# 安装与管理插件

插件可以给主面板增加页面、快捷操作或后台能力。只安装你了解来源的插件。

## 导入插件

Tempo 支持插件目录和 `.zip` 包。导入前，包的根目录中必须有 `manifest.json`。

1. 打开 **设置 → 插件管理**。
2. 选择 **导入目录** 或 **导入 ZIP**。
3. 检查插件名称、版本和声明的能力。
4. 启用插件。
5. 回到主面板，搜索插件名称。

导入只是把插件加入 Tempo。插件是否立即可用，还取决于它有没有后台脚本。

## 信任与 Node 运行时

插件分为两类：

| 插件内容 | 你需要做什么 |
| --- | --- |
| 只有页面 | 导入并启用即可 |
| 包含后台脚本 | 安装插件 Node 运行时，再明确点“信任” |

后台脚本的能力接近本机 Node 程序，可能读写文件、联网或启动进程。因此 Tempo 不会在你信任前运行它。

信任插件前，至少确认：

- 插件来自你认可的作者或仓库。
- 插件声明的能力符合它的用途。
- 更新后的版本没有突然增加不相关的能力。

## 启用、停用与卸载

- **停用**：暂时移除插件入口并停止后台。当前版本还会清空该插件的 Host KV 与页面 Session；Runtime 文件数据目录会保留。
- **卸载**：移除插件包。操作前留意界面是否提示保留或删除数据。
- **更新**：导入同一插件的新版本后，按插件列表中的提示切换版本。

插件出现异常时，先停用再重新启用。带后台脚本的插件还可以检查运行时状态和日志。

## 插件配置与 AI 工具

有配置项的插件会在插件详情中显示“插件配置”。这些设置由 Tempo 保存，插件只能读取自己的数据。

插件声明的 MCP 工具默认不会暴露给 AI 客户端。只有你在插件详情中打开 MCP 暴露，并启用具体工具后，外部客户端才能调用。
