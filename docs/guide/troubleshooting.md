# 遇到问题

先找到最接近的现象。这里优先给出能直接操作的检查步骤。

## 快捷键没有反应

1. 从系统托盘或菜单栏确认 Tempo 正在运行。
2. 打开 Tempo 的 **设置 → 快捷键**。
3. 把冲突的快捷键改成其它组合，再测试一次。
4. Windows 用户如果 `Alt + Space` 打开了系统窗口菜单，建议改用其它组合。

## 搜不到本机应用

刚启动时，Tempo 需要读取本机应用列表。等待片刻后再搜索完整应用名。

如果仍然没有结果，退出 Tempo 后重新打开。某些便携应用或系统限制下的应用可能无法被自动发现。

## 剪贴板没有新记录

在 **设置 → 插件管理 → 剪贴板** 中确认“记录剪贴板”已打开。

受保护应用、密码框或特殊格式的内容可能不会进入历史。可以先在普通文本编辑器中复制一段文字，判断基础记录是否正常。

## 屏幕使用时间没有数据

Tempo 只统计它运行期间的前台应用。请确认 Tempo 没有完全退出，并使用几个普通桌面应用后再查看。

部分全屏、受保护窗口或平台权限限制可能导致统计不完整。

## 插件导入后不能使用

按顺序检查：

1. 插件是否已启用。
2. 插件是否包含后台脚本；如果包含，Node 运行时是否已安装。
3. 是否已经信任该版本。
4. `manifest.json` 是否位于插件包根目录。
5. 停用后重新启用，并查看插件运行日志。

还不确定“信任”和“启用”的区别时，查看 [安装与管理插件](/guide/plugins#信任与-node-运行时)。

## 仍然无法解决

到 [GitHub Issues](https://github.com/joooooooojo/tempo/issues) 搜索相同问题。新建问题时请附上：

- 操作系统和 Tempo 版本。
- 能稳定复现问题的步骤。
- 实际看到的提示或日志。
- 插件问题对应的插件 ID 与版本。

不要在公开 Issue 中粘贴令牌、密码、私人剪贴板内容或其它敏感数据。
